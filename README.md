# 🎓 NU Exam Schedule — Spring 2026

A fast, student-friendly exam schedule lookup tool for **Nile University** students.

Built by **Peter Yakoub** · Senior Computer Engineering Student

🔗 **Live site:** [peter9991.github.io/nu-exam-schedule](https://peter9991.github.io/nu-exam-schedule)

---

## What it does

Enter your student ID and instantly see all your Spring 2026 final exams — date, time, room, and group — without digging through a spreadsheet.

- 🏛️ **Room** exams shown in blue
- 💻 **Computer Lab** exams shown in purple  
- ✏️ **Drawing Hall** exams shown in teal

---

## How it works

All student data (~4,265 IDs, 901 exam sessions) is embedded directly inside `index.html` as a JavaScript object. No backend, no database, no API — everything runs locally in the browser.

Just push `index.html` and it works.

---

## Disclaimer

> This tool is made to help students easily view their schedule.  
> **Please always verify your exams on the official portal Excel file.**

---

## Stack

- Plain HTML / CSS / JavaScript — zero dependencies
- Data source: Official Spring 2026 Final Exam Schedule (Excel)

---

## Usage

Open `index.html` in any browser, or visit the GitHub Pages link above.
Type your student ID (e.g. `231001234`) and press Search.
